# Barème BCMA : accord d'utilisation

- **Date** : 21/11/2026.
- **Objet** : reprise dans Fourmy du barème BCMA des matériels agricoles, tel que publié dans les guides pratiques du CEGARA « Coût des façons culturales » (grandes cultures et viti-arbo), édition 2024.
- **Accord** : CEGARA et BCMA, confirmé par l'équipe Fourmy le 21/11/2026 (échange hors dépôt).
- **Périmètre** :
  - performance par heure (débit de chantier) pour le temps de travaux de l'assolement ;
  - prix d'achat, utilisation annuelle, coûts fixes et variables pour le module économique (temps 3).
- **Conditions d'usage dans Fourmy** :
  - source citée à chaque affichage d'un débit ou d'un coût qui en vient (« Barème BCMA, guides CEGARA », édition) ;
  - données versionnées dans `packages/certification-refs/data/bcma-2024.csv`, extraites par `scripts/extract-bcma.ts` ;
  - les PDF ne sont pas versionnés.
- **Mise à jour** : chaque nouvelle édition s'extrait avec le même script (`bcma-<édition>.csv`), sous le même accord, à confirmer par l'équipe.
